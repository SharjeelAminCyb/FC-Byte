# FC Byte

*Never trust the input.*

FC Byte is a football-themed, intentionally vulnerable web application built as a capture-the-flag (CTF) challenge. it gives IT and cybersecurity students a safe place to practice finding and exploiting common web vulnerabilties.

## Warning

This application is intentionally vulnerable. Run it only on your own machine and never deploy it to the internet.

## Status

Work in progress.

## Planned levels

| Level | Vulnerability |
| --- | --- |
| 1 | Information disclosure |
| 2 | SQL injection |
| 3 | IDOR |
| 4 | Business logic flaw |
| 5 | Weak secret key |
| 6 | Stored XSS |

## Tech stack

Python, Flask, SQLite, HTML and CSS
